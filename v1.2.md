# Versão 1.2 — Debug do Jornal, Fontes por Categoria e Agente de IA

> **Data:** maio de 2026
> **Versão anterior:** 1.1
> **Arquivos alterados:** `journal.js`, `journal.css`, `durando-mind.html`

---

## ✅ O que foi implementado

### Seleção de fontes por categoria
- Cada categoria do Jornal agora tem fontes pré-definidas selecionáveis pelo usuário
- Exemplos: IA → OpenAI Blog / TechCrunch / The Verge / MIT Tech Review; Futebol → GE / ESPN / UOL / Trivela; Mercado → Valor Econômico / InfoMoney / Bloomberg / Reuters
- Preferência salva em `localStorage` por categoria (`durando_journal_source_{catId}`)
- Mudar a fonte invalida o cache da categoria e dispara novo fetch automaticamente
- UI: dropdowns no painel de Configurações do Jornal, um por categoria

### Proposta de Agente de IA
- Documento completo em `docs/agente_jornal.md`
- Arquitetura: Firebase Function com `onSchedule` (06:00 e 12:00)
- Fluxo: busca → score de relevância via Groq → enriquecimento paralelo (resumo + insights) → Firestore → push FCM
- Custo estimado: gratuito no Spark, ~R$0,10/mês no Blaze
- Estrutura de dados do cache centralizado documentada

## 🔧 O que foi melhorado

### CSS do Jornal — reescrito completamente
- `journal.css` anterior usava nomes de classe que não existiam no HTML/JS gerado (`journal-card`, `journal-feed`, `journal-cat-btn`, etc.)
- Reescrito com os nomes corretos: `.news-card`, `.news-img`, `.news-body`, `.news-kicker`, `.news-title`, `.favorite-btn`, `.journal-grid`, `.journal-chip`, etc.
- Cards agora têm layout, imagem, hover e botão de favorito visíveis
- Painel de detalhe com as classes corretas: `.jd-back`, `.jd-header-actions`, `.jd-open-link`, `.jd-section`, `.jd-section-label`
- Estado da fonte (real / cache / fallback) com indicador colorido
- Completamente responsivo para mobile

### Markdown no resultado de IA
- `mdLite()` reescrito para processar markdown real: `## headings`, `- listas`, `**negrito**`, `*itálico*`, `` `code` ``, `---` separadores e parágrafos
- Resultados de IA agora aparecem formatados com seções visuais, não como texto bruto

### Prompts de IA melhorados
- Prompt de **Resumo** reformulado: exige O QUÊ, QUEM, ONDE, QUANDO; adiciona seção **Impacto** explícita; instrui a evitar frases genéricas; formato de jornalista sênior

---

## 🐛 Bugs corrigidos

- **Cards invisíveis no Jornal**: todos os `news-card`, `news-img`, `journal-grid` e variantes estavam sem CSS (nomes errados no arquivo). Corrigidos com reescrita total do `journal.css`
- **Resultado de IA como texto bruto**: `mdLite()` não processava `##`, `- listas` nem parágrafos; reescrito para processar linha a linha
- **Painel de detalhe sem estilo**: `.jd-back`, `.jd-header-actions`, `.jd-open-link`, `.jd-section` não tinham CSS; adicionados ao `journal.css`
- **`renderJournalCatSourcesUi` com erro de sintaxe**: `onchange` inline com aspas simples dentro de string simples causava `SyntaxError`; corrigido usando `addEventListener` via `querySelectorAll`

---

## ⚠️ Observações e limitações

- O Agente de IA (`journalAgent`) ainda **não está deployado** — é uma proposta documentada que requer plano Blaze
- A seleção de fonte por categoria usa query personalizada no Google News RSS — algumas fontes específicas (ex: `site:valor.globo.com`) podem ter RSS limitado
- `mdLite()` processa markdown simplificado; não suporta tabelas ou blocos de código multiline
